# MReact-02. Чистота render и выбор курса

React 19.3.1, Vite 8.3.8, Node 24.

```bash
npm install
npm run dev -- --host 127.0.0.1
```

## Что сделал

- `CourseCard.jsx` — чистый компонент: по `course` и `selected` возвращает JSX, наружу ничего не пишет. Кнопка «Выбрать» вызывает `onSelect(course.id)`.
- `App.jsx` — `handleSelect` пишет id в `localStorage` и сохраняет его в состоянии. Начальное значение читается лениво: `useState(() => localStorage.getItem(...))`.
- Кнопка «Перерисовать» нужна, чтобы вызвать повторный render без выбора.

## Почему не Effect

Исходный код писал в `localStorage` прямо при вычислении карточки. Render должен быть чистым: один и тот же вход даёт один и тот же JSX без побочных действий, а React вправе вызывать его повторно (StrictMode, обновление родителя).

Если перенести запись в `useEffect(() => localStorage.setItem(...), [course.id])`, запись всё равно произойдёт без клика, при монтировании карточки, и сохранит id курса, который пользователь не выбирал. Effect выполняется после commit из-за самого отображения, а не из-за действия пользователя. Здесь запись нужна только как ответ на клик, поэтому место ей в обработчике. Effect нужен для синхронизации с внешней системой, а не для реакции на событие.

## Самопроверка

Очищенный `localStorage`, перехваченный `Storage.prototype.setItem`:

- Загрузка страницы: `selected-course` = `null`, записей 0.
- 3 нажатия «Перерисовать»: `null`, записей 0.
- «Выбрать» на третьей карточке и ещё 2 перерисовки: `selected-course` = `next`, записей 1.
