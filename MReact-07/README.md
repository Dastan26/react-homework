```bash
npm install

```

Страница: https://dastan26.github.io/react-homework/MReact-07/

## Что сделал

**`CourseListView.jsx` — представление.** Получает `items`, `emptyText`, `onSelect` и необязательный `selectedId` и только рисует их. Не импортирует `courses.json`, не читает `localStorage`, не делает `fetch`, не хранит state. Если `items` пустой — выводит `emptyText`. Иначе для каждого курса рисует карточку на `Panel` из MReact-05 с кнопкой «Выбрать», которая вызывает `onSelect(course.id)`. Что делать с этим id, решает родитель.

**`CatalogContainer` (в `App.jsx`) — контейнер.** Хранит `query` и `selectedId`, импортирует `courses.json`, фильтрует курсы по названию и передаёт представлению готовые `items`, текст для пустого результата и `onSelect={setSelectedId}`. Над списком показан выбранный курс.

**`ViewDemo` (в `App.jsx`) — представление отдельно, без контейнера:**

- `items={courses}` — полный список;
- `items={[]}` — пустой массив, виден только `emptyText`.

Callback в демо записывает полученные id в строку «Вызовы onSelect», чтобы было видно, что кнопка передаёт именно id.
