# MReact-05. Карточка через композицию

React 19.3.1, Vite 8.3.8, Node 24.

```bash
npm install
npm run dev -- --host 127.0.0.1
```

Страница: https://dastan26.github.io/react-homework/MReact-05/

## Что сделал

- `Panel.jsx` — универсальная рамка с тремя слотами: `title`, `children` и `actions`. Внутри нет ветвления по id курса или по типу содержимого. Panel не знает, что в ней лежит, — содержимое и кнопки передаются снаружи.
- Область `actions` выводится только если её передали. Если `actions` равен `null`, обёртки `.panel-actions` в DOM нет совсем — ни пустого блока, ни лишней кнопки.
- Заголовок — `<h2>` внутри `<section aria-labelledby>`. Длинный заголовок переносится (`overflow-wrap: anywhere`), даже если в нём слово без пробелов, и не растягивает карточку.

Panel используется в двух сценариях:

1. **Карточка курса** (`CourseCard`): заголовок — название курса, в `children` категория и места, в `actions` кнопка «Выбрать». Решение, показывать ли кнопку, принимает `CourseCard`: у курса без свободных мест (`typescript`) `actions={null}`, в карточке написано «Мест нет».
2. **Блок фильтра** (`CategoryFilter`): заголовок «Фильтр», в `children` выбор категории, в `actions` кнопка «Сбросить». Она появляется только когда выбрана не «Все».

Данные — `courses.json` из условия плюс один вымышленный курс с очень длинным названием для проверки.

Кнопки — обычные `<button>`, поэтому доступны с клавиатуры (Tab, Enter, Space). У выбранного курса `aria-pressed="true"`. Кнопка «Сбросить» после нажатия исчезает, поэтому обработчик возвращает фокус в выпадающий список: иначе фокус потерялся бы на `body`.

## Самопроверка

Проверено в браузере, React 19:

- Панелей 6 (фильтр + 5 курсов), областей actions 4, пустых областей actions 0. У «Типизация данных» области actions нет, у фильтра в начальном состоянии тоже нет.
- Длинный заголовок переносится на несколько строк, `scrollWidth` заголовка равен его ширине — ничего не вылезает за карточку.
- Только клавиатура: Tab → список категорий, Tab → «Выбрать», Enter — курс выбран (`aria-pressed="true"`). Shift+Tab → список, стрелка вниз — Frontend, появилась кнопка «Сбросить». Tab → «Сбросить», Enter — категория снова «Все», кнопка исчезла, фокус вернулся в выпадающий список.
