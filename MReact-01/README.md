# MReact-01. Render и commit на счётчике

React 19.3.1, Vite 8.3.8, Node 24.

```bash
npm install
npm run dev -- --host 127.0.0.1
```

## Что сделал

- `App.jsx` — родитель со счётчиком, кнопками смены title (берётся из `courses.json`) и перемонтажа ребёнка через `key`.
- `CourseTitle.jsx` — ребёнок: `console.log` в теле, `MutationObserver` на `<p>` в `useEffect`, в cleanup `disconnect()`.
- `addMutation` в `useCallback` и `setObservers` стабильные, поэтому эффект не переподписывается на каждом рендере.

## Наблюдения

Клик «+1»: в консоли появляется `render CourseTitle`, а изменений DOM 0. Ребёнок рендерится, потому что рендерится родитель, но текст тот же, и на commit React DOM не трогает. Лог в теле компонента DOM не меняет.

Смена title: снова render, плюс одна мутация `characterData`. React поменял текст в текстовом узле. После этого родитель ещё раз рендерится (обновился список мутаций), ребёнок тоже, но новых мутаций нет.

Перемонтаж: cleanup старого observer, effect нового. Подписок всегда 1.

## StrictMode

- Render в dev вызывается дважды, чтобы ловить нечистые компоненты. Коммит при этом один.
- При монтаже effect → cleanup → effect, в консоли счётчик 1 → 0 → 1. Так проверяется, что cleanup правильно снимает подписку. После перемонтажа то же самое, в итоге 1.
- В production (`npm run build && npm run preview`) этого нет.

## Самопроверка

- 2 клика «+1»: 4 лога render (StrictMode), изменений DOM 0.
- Смена title: 1 мутация.
- 2 перемонтажа и смена title: подписок 1, мутация записалась один раз.
